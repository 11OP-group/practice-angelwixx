# GladiatorBattle

# Практическая работа по МДК02

Консольное приложение на C#, которое имитирует пошаговый бой между двумя гладиаторами.

# Как работает программа

1. Сначала пользователь вводит информацию о первом гладиаторе:

- Имя;
- Здоровье;
- Прочность брони;
- Процент защиты.

2. Затем аналогичные данные вводятся для второго гладиатора.

3. Программа проверяет корректность введённых значений:

- Здоровье должно быть больше 0;
- Прочность брони должна быть больше 0;
- Защита должна находиться в диапазоне от 0 до 100%.

Если введены неправильные данные, программа предлагает повторить ввод нужного параметра.

4. Сражение проходит по раундам и продолжается до тех пор, пока здоровье обоих гладиаторов не станет равным 0 или меньше.

5. В каждом раунде каждый гладиатор получает случайный удар от 10 до 100 единиц. Общее количество нанесённых ударов увеличивается на 2.

6. Размер полученного урона определяется с учётом состояния брони на начало раунда:

- Если броня присутствует и сила удара превышает её прочность, урон вычисляется по формуле:
  
  "Урон = броня - броня * защита / 100 + (удар - броня)"

- Если броня есть, но удар не превышает её прочность:
  
  "Урон = удар - удар * защита / 100"

- Если брони нет:
  
  "Урон = удар"

7. По такому же принципу рассчитывается урон для обоих участников боя.

8. После расчёта урона здоровье каждого гладиатора уменьшается на соответствующее значение.

9. После получения урона прочность брони уменьшается на величину полного нанесённого удара:

- Если прочность брони стала равна 0 или меньше, броня ломается и её прочность устанавливается в 0;
- Если броня выдержала удар, программа выводит соответствующее сообщение.

10. По окончании каждого раунда программа отображает:

- Полученный каждым гладиатором урон;
- Оставшееся здоровье;
- Текущую прочность брони.

Значение здоровья не выводится ниже 0.

11. Когда бой заканчивается, программа определяет победителя:

- Если здоровье обоих гладиаторов равно 0 или меньше, объявляется ничья;
- Если здоровье первого гладиатора равно 0 или меньше, выигрывает второй;
- В остальных случаях победителем становится первый гладиатор.

12. В завершение выводится общее количество ударов, нанесённых за весь бой.
